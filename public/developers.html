Relay Developers

One open API: send signals in, read the shared record, add responders.

Dashboard  |  Partner app simulator  |  OpenAPI (YAML)
Status: the API is open today and needs no key; intake is rate limited. Partner keys, responder accounts and regulator views are on the roadmap and are marked below. Nothing on this page hides that.

What you can do

Send signals BUILT

Post a report as text or a voice note and name your application as the source. Relay classifies it, finds the place, and merges it into an existing case when it is the same problem.

Read the shared record BUILT

Look up any case: status, responsible owner, SLA, history, sources and independent verification, with sensitive details masked.

Respond and oversee ROADMAP

Responder accounts that accept assignments and post actions; regulator and NGO views; alerts when a case in your area changes.

Embed Relay in your product BUILT

    

      
Services that reach last-mile communities can add a "Report a problem" button and a case tracker to their own site or app with one line.
        Reports carry your application's name as the source and join the shared record. The widget calls only the public API and stores nothing in the browser.

      

      
Optional attributes: data-label, data-color (#RRGGBB), data-api. See it on a simulated partner website:
        /embed-demo.html. The public read and report endpoints allow cross-origin calls; demo controls and the WhatsApp webhook do not.

Responder categories and access classes

    

      
Who connects
Data partners and aggregators; government agencies and local government; security and police liaison; NGOs and civil society; community responders and mediators; regulators and oversight bodies.

      
Public BUILT
Masked text, rounded coordinates, status, owner, SLA, history and sources.

      
Restricted ROADMAP
Fuller detail and aggregate data for verified regulators, NGOs and government bodies.

      
Protected DESIGNED FOR
Sensitive cases (gender-based violence, whistleblowers, minors), visible only to designated organisations.

    


    
Relay is a proof of concept built for the Andela x Open Society Foundations "Information You Can Trust" challenge. Responder behaviour in the demo is simulated.
